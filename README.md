# Fullstack Mini Projects

A compact set of small fullstack experiments for practicing UI, back-end logic, and database thinking.

## Included project

### Task Board

A simple PHP + JavaScript task board with a SQL schema.

## Stack

`PHP` · `JavaScript` · `HTML` · `CSS` · `SQL`

## Run

Serve the project with any local PHP server:

```bash
php -S localhost:8000 -t task-board
```
