# Contributing

Thanks for improving Fullstack Mini Projects. Keep changes focused, secure, and dependency-light.

1. Fork or branch from `main`.
2. Run `php tests/run.php` and PHP syntax checks before submitting.
3. Add or update tests for behavior changes.
4. Never commit databases, credentials, personal task data, or generated artifacts.
5. Keep English and Arabic README sections aligned when documented behavior changes.

By contributing, you agree that your contribution is licensed under the repository's MIT License.
